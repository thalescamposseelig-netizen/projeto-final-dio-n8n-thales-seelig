Projeto Final DIO n8n
O projeto é um fluxo simples para notificação de novos leads. Fluxo inicial: formulário → planilha → e-mail
Objetivo: quando alguém preencher um formulário, o n8n registra os dados em uma planilha e envia uma confirmação por e-mail.
Os nodes usados: trigger form n8n > edit fields > sheets > gmail
